# 📊 Customer Churn Prediction using ANN

## 🚀 Overview

This project predicts whether a customer is likely to leave a subscription-based platform using an Artificial Neural Network (ANN). The model analyzes customer behavior and activity patterns to identify potential churn cases.

A simple Streamlit interface is used for real-time prediction.

---

## 🧠 Problem Statement

Customer churn affects business growth and revenue. The goal of this project is to predict customers who may leave the platform so businesses can take preventive actions and improve customer retention.

---

## ⚙️ Tech Stack

- Python
- Pandas
- NumPy
- Scikit-learn
- TensorFlow / Keras
- Streamlit

---

## 🔄 Workflow

### 1. Data Preprocessing
- Removed unnecessary data
- Encoded categorical features
- Applied feature scaling
- Split dataset into training and testing data

### 2. Model Building
- Built an Artificial Neural Network (ANN)
- Used Dense and Dropout layers
- Applied binary classification for churn prediction

### 3. Training
- Used Adam optimizer
- Used Binary Crossentropy loss function
- Achieved around 89% accuracy

### 4. Evaluation
- Evaluated model using:
  - Accuracy
  - Precision
  - Recall
  - F1 Score
  - Confusion Matrix

### 5. Deployment
- Developed a Streamlit application
- Enabled real-time churn prediction through user input

---

## 📈 Model Performance

- Accuracy: ~89%
- Precision: 0.89

- F1 Score: 0.89
